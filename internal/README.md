# 内部文档区 · 禁止部署

## 这个目录放什么

本目录存放**不适合给孩子查看**的成人内部材料：

- 专家团内部讨论记录与决策过程
- 财务模型与家庭财务约束
- 红队审查意见与退回记录
- 家长版季度规划报告
- 技术审计与工程修复文档

## 重要：不面向孩子

**这些内容不面向孩子。** 家长和孩子的日常学习不应访问本目录。

原因：其中的费用数字、资产与退休规划、成人决策权衡、专家团内部争论，
都属于成人才信息和家庭内部信息。孩子只需要看自己的学习工作台，
不需要知道家庭财务状况或成人如何权衡教育投入。

## 技术保障

`.github/workflows/deploy.yml` 的 rsync 部署已 `--exclude='internal/'`，
因此**即使误提交也不会上线**——部署时该目录被完整排除，不会出现在网站服务器上。

## 子目录说明

| 子目录 | 内容 |
| --- | --- |
| `team-review/` | 专家团六位专家产出汇编、红队往返审查意见、退回记录 |
| `finance/` | 家庭财务约束档案（资产、收入、退休规划）、财务测算模型源码 |
| `engineering/` | 学习工作台技术审计报告、修复实施计划、长期修复路线图 |
| `planning/` | 两份定制化学习方案建议（专家团产出，未脱敏） |
| `parent-reports/` | 家长版季度教育规划报告（决策依据） |

## 如需转为孩子可见

请先把文件移到 `analysis/` 或根目录，并**删除其中的费用、成人决策、内部讨论内容**，
再重新检查一遍是否还有敏感信息残留。
