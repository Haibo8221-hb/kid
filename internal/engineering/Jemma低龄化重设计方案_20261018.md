# Jemma（jemma.html）低龄化重设计方案（2026-10-18）

> 状态：**待 Bo 确认后实施**。本文取代 `页面重构方案_20261018.md` 中 Jemma 部分的策略（原策略是"折叠迁移"，按 Bo 新要求升级为"面向低龄学生重新设计"）。
> 设计依据：2026-10-18 对 jemma.html 全文（约 2390 行）走查 + 项目背景（Y9、低压力探索期原则、14 岁前不锁定专业）。

---

## 0. 设计原则（对齐家庭宪章）

1. **每屏只讲一件事**：任何一屏只放 1 个主动作 + 至多 3 个辅助信息；首页一屏内能完成"今天做什么"。
2. **短句、图示、步骤化**：单条文案 ≤ 20 字（英文 ≤ 12 词）；能用图标/徽章/步骤条就不用段落；杜绝现存 600 词长文。
3. **互动优先于阅读**：能点、能勾、能选的，不写成说明文字；每次点击必须有即时反馈（动画/声音感/toast）。
4. **压力小一点、兴趣大一点**：删除"风险热图"这类成人分析框架的孩子端呈现，改为"我在注意的 3 件事"；比赛相关文案统一"结果是反馈，不是判决"口径。
5. **内容不丢，只换层级**：现有所有信息保留，但按"今天用 / 这周用 / 以后看"分三层收纳（见 §3 迁移映射表）。
6. **她的事她决定**：保留并强化 Latin 决定卡与反思卡（自主权是低龄期的核心设计）。

## 2. 语言层重构（最关键的一层）

**规则**：一句话能说清的不用两句；术语第一次出现时配一个生活比喻；删除成人分析框架词（Probability·Impact、viability、Confirmed·Positive 等）。

| 现状（示例） | 重新设计后 |
|---|---|
| 小贴士 detail 600+ 词长文（如 IMC 备赛卡整段英文） | **三行结构**：🔍 一句话方法（≤15 词）+ 💡 为什么（≤20 词）+ ✅ 现在就做（1 个动作）。例：「先做会做的题」「比赛时先拿稳前 15 题，卡住超过 3 分钟就跳过去」「今天：找一份 IMC 往年卷，只做前 15 题」 |
| 「Resolved ✓ — 3月『分析会卡住』→ 10月 Effort Above（Dr McKendry）」 | 「🗣 英语：从'卡住'到 Above，你搞定了！」 |
| 「STEM 课堂努力度偏软 — Med Probability·Med Impact…轻推不施压」 | 「⚡ 上课多举手：Physics / Computing / Chemistry，你明明都会」 |
| 「Risk Heatmap」整卡 | 删除框架，改为 Today 页一张小便签：「🌟 我在注意的 3 件事：① 上课举手 ② Latin 想清楚 ③ 比赛去试试」 |
| 「Chemistry 44% — Exam gap is real. A-level viability in question」 | 「🧪 化学：7月 44% → 10月 6 级，爬坡中，冲 7！」 |
| 「这是只属于你一个人的学习台……爸爸妈妈也可以陪你一起看」 | 「👋 Hi Jemma！这是你的小空间。你的星星、你的错题、你的计划，都只属于你。」 |

**双语口径维持现状**（标题英文、讲解中文），但全部短句化。

## 6. 技术实现与流水线

- **零新依赖**：全部沿用现有栈（原生 HTML/CSS/JS + assets/kid.js + assets/kid.css）；不引框架、不引图标库（emoji 满足低龄视觉）。
- **首屏性能**：Today 一屏 DOM 节点约减少 60%（13 区块折叠为 5）；雷达图/雷达 canvas 懒入展开态；无新增网络请求（kid.js 已有，仅 +8KB 源码、gzip <3KB）。
- **流水线**：无构建步骤，rsync 原样推送；`?v=20261018` bump 两个 script 标签；`tools/smoke_test.cjs` 增加 jemma.html 双页回归（onclick 悬空检查对本次大量结构调整最有价值）；`tests/check_links.py` 默认扫描已含 jemma.html，新入口（My Stuff 折叠组内链接）必须指向真实文件——`downloads/`、`resources/` 已在 SERVER_ONLY_DIRS 跳过名单。
- **红线不变**：登录守卫、`/api/*`、data/logs 服务器唯一真源、deploy key 管理，全部不碰。

## 7. 验证方式

1. `node tools/smoke_test.cjs`（双页）——悬空 onclick/关键函数/弹窗点击。
2. `python tests/check_links.py` + `python tests/verify_p0_fixes.py`。
3. 本地静态服务手工过 5 屏：Today 一屏原则（1280×800 无滚动完成打卡）、勾选→彩带→streak、Latin 决定回显、徽章展开、My Stuff 四卡+两折叠、My Plan 三折叠。
4. 移动端 390px 宽度过一遍（现有媒体查询保留）。
5. 上线后请 Jemma 本人点一遍——低龄设计的最终裁判是用户本人。
