Q38 — Combining Transformations: Full Solution

Year 8 Maths · Topic: Combining Transformations (★★★) · 3 marks

📋 The Question

Shape P is enlarged by scale factor 2 from centre (0, 0), then translated by vector (−3, 1).

A point on P is (2, 3).

(a) Find the final coordinates of this point after both transformations. [2 marks]

(b) Describe a single transformation equivalent to both. [1 mark]

📐 Knowledge Point 1 — What is an Enlargement?

Definition

An enlargement changes the size of a shape by a scale factor (k) from a fixed point called the centre of enlargement.

🔑Key rule: Every point moves along a ray from the centre. The distance from the centre is multiplied by k.
📏If k > 1: the shape gets bigger. If 0 < k < 1: the shape gets smaller.
📍If the centre is the origin (0,0), you simply multiply both coordinates by k:
(x, y) → (k × x, k × y)

Example: Enlargement ×2 from (0,0)

Original pointMultiply x by 2Multiply y by 2Image point
A(1, 2)1 × 2 = 22 × 2 = 4A'(2, 4)
B(3, 1)3 × 2 = 61 × 2 = 2B'(6, 2)
P(2, 3)2 × 2 = 43 × 2 = 6P'(4, 6)

Fig 1: Enlargement ×2 from origin O. Point P moves along ray OP — its distance from O doubles.

📐 Knowledge Point 2 — What is a Translation?

Definition

A translation slides every point of a shape by the same distance in the same direction. The shape does NOT rotate, reflect, or change size.

🔑A translation is described by a column vector (a, b):
• a = move right (positive) or left (negative) in the x-direction
• b = move up (positive) or down (negative) in the y-direction
✏️To apply a translation: add the vector to each coordinate:
(x, y) → (x + a, y + b)

Vector (−3, 1) means:

Move LEFT 3 (x − 3)

Move UP 1 (y + 1)

(4, 6) → (4−3, 6+1) = (1, 7)

Visual check:

4 − 3 = 1 ✓ (moved left)

6 + 1 = 7 ✓ (moved up)

The shape keeps its size and orientation — it just slides.

Fig 2: Translation (−3,1) slides P' left 3 and up 1 to P''(1,7). Axis labels show the coordinate scale.

🔗 Putting It Together — The Two-Step Process

Complete working for part (a):

(2, 3) — enlarge ×2 → (4, 6) — translate (−3,1) → (1, 7)

Answer (a): The final coordinates are (1, 7). ✓

📐 Knowledge Point 3 — Finding the Single Equivalent Transformation

Why does this matter?

Two transformations done one after another can often be replaced by ONE transformation. This is called composition of transformations. Finding the single equivalent saves work and reveals the "net effect."

Method: Algebraic Approach

Step 1 — Write the combined effect as a formula

Start with any point (x, y) on P:

After enlargement: (2x, 2y)

After translation: (2x − 3, 2y + 1)

So the combined transformation sends (x, y) → (2x − 3, 2y + 1)

Step 2 — Guess the type of single transformation

Since both transformations involve ×2, the single transformation is likely another enlargement with scale factor 2, but from a different centre — call it C(a, b).

Why not a translation? Because the coordinates have ×2 in them — that's enlargement, not translation.

Why not a rotation or reflection? Because the shape changes size (×2), which only enlargement does.

Step 3 — Write the formula for "enlargement from C(a, b) by ×2"

For any point (x, y), enlargement ×2 from C(a, b):

The vector from C to the point is (x − a, y − b)

Multiply this vector by 2: (2(x − a), 2(y − b)) = (2x − 2a, 2y − 2b)

Add back to C: (a + 2x − 2a, b + 2y − 2b)

Simplified: (2x − a, 2y − b)

Step 4 — Equate and solve

Combined two-step result: (2x − 3, 2y + 1)

Single enlargement from C(a, b): (2x − a, 2y − b)

x-coordinatey-coordinate
Two-step2x − 32y + 1
Single enlargement2x − a2y − b
Equate2x − 3 = 2x − a2y + 1 = 2y − b
Solvea = 3b = −1

Answer (b):

The single equivalent transformation is an enlargement by scale factor 2 from centre (3, −1).

🔍 Visual Verification — Does It Work?

Fig 3: The single enlargement from C(3,−1). Vector CP'' is exactly twice CP — proof it works.

Check with the formula:

For P(2, 3), enlargement ×2 from C(3, −1):

x → 3 + 2(2 − 3) = 3 + 2(−1) = 3 − 2 = 1 ✓

y → −1 + 2(3 − (−1)) = −1 + 2(4) = −1 + 8 = 7 ✓

Result: (1, 7) — matches our two-step answer!

⚠️ Common Mistake — Order Matters!

Enlargement then Translation ≠ Translation then Enlargement

Transformations are NOT commutative — changing the order gives a different result.

Our question: Enlarge THEN translate

(2,3) → (4,6) → (1,7)

Final: (1, 7) ✓

Single equivalent: enlarge ×2 from (3,−1)

If reversed: Translate THEN enlarge

(2,3) → (−1,4) → (−2,8)

Final: (−2, 8) ✗ Different!

Single equivalent: enlarge ×2 from (6,−2)

The centre of the single enlargement changes depending on the order. Always follow the order given in the question!

The trick to part (b):

The combined formula is (x, y) → (2x − 3, 2y + 1).

An enlargement ×2 from (a, b) has formula (x, y) → (2x − a, 2y − b).

Match the numbers: a = 3, b = −1. Done!
