## 二、影响评估

| 问题 | 影响评估 |
|---|---|
| 错题 POST/DELETE 405 + 假成功 toast | **数据丢失风险（高）**：用户以为已保存，实际未落盘；删除同样静默失败，错题库只增不减 |
| child 参数路径穿越 | **安全（高）**：5 个接口可被构造 `child=../../` 写出/覆盖 data/ 目录文件；同库其他接口已校验，属一致性漏洞 |
| 默认密码 + Cookie 无 secure | **安全（中高）**：空环境变量时任何人可用默认密码登录；Cookie 明文传输可被截获 |
| v2 无鉴权 + 登出不调后端 | **安全（中）**：v2 入口仍暴露（index.html:41-59），绕过登录直达页面；登出后会话实际仍有效 |
| 6 条死链 | **体验（中）**：资源区点击 404，家长/孩子信任度下降 |
| error_save 字段不匹配、无 id | **功能（高）**：保存的数据前端读不回来，等于保存链路整体不可用 |
| 复习表/PETAL 双口径/smcGrade 标准矛盾 | **内容正确性（中高）**：孩子按错误标准复习或自评，直接影响备考判断 |
| 错题 276KB 无分页 | **性能（低中）**：首屏加载与渲染变慢，113 条量级尚可容忍，但随积累线性恶化 |
| Notes/mastered 仅 localStorage | **可靠性（中）**：清缓存/换设备即丢；两台前端重复实现也使状态分裂 |

## 六、验证方式与验收标准

### P0 验收（逐项必须通过）

| 项 | 验证方式 | 验收标准 |
|---|---|---|
| #1 错题增删 | 浏览器新增 1 条错题→刷新仍在；删除 1 条→刷新已消失；断网时操作 | 成功路径数据真实落盘（data/ 文件含新记录）；失败时 toast 显示错误而非 "Saved"；curl -X POST/DELETE 返回 200 而非 405 |
| #2 路径穿越 | `curl "/api/planner/child/../../x?..."` 及 tasks/chat/chat_stream/review 同法 | 全部被 400/403 拒绝；data/ 目录无新增异常文件 |
| #3 密码与 Cookie | ① 不设环境变量启动；② 登录后检查 Set-Cookie 头 | ① 启动拒绝并打印告警；② 修改默认密码后旧密码失效；③ Cookie 含 Secure/HttpOnly/SameSite=Lax |
| #4 鉴权与登出 | ① 无痕窗口直接开 v2/diya.html；② 登录后 logout 再用旧 Cookie 访问 API | ① 无会话被重定向 login；② logout 后旧会话 401；③ index 不再有无保护 v2 入口 |
| #5 死链 | 资源健康检查脚本跑全站 href；逐条点击 6 个原死链 | 全部链接 200 或条目已下架；脚本输出 0 失效 |
| #6 字段契约 | 新增错题后立即在错题本查看详情 | 新增记录可完整回显（题干/我的答案/正确解答/id），存量 113 条迁移后同样可回显 |
