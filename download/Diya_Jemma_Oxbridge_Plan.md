## 二、Diya 完整作战方案（Year 10 → Year 12）

### 2.1 细分方向选择（关键岔路口）

Diya现在需要定一个更细的方向，因为工程/医学/自然科学的附加考试路径完全不同。**基于March 2026成绩单分析：**

| 方向 | 附加考试 | 核心要求 | 匹配度 |
|------|---------|---------|--------|
| **工程**（电子/机械/化学） | ENGAA (Oxford) / ESAT (Cambridge) | MAT + 物理竞赛 | ⭐⭐⭐⭐ **强项匹配** |
| **数学/CS** | MAT + STEP 2/3 | MAT 65+ / STEP S | ⭐⭐⭐⭐ **强项匹配** |
| **自然科学**（物理/化学） | NSAA (Cambridge) / 无特定 (Oxford) | BPhO/UKChO成绩 | ⭐⭐⭐⭐ **强项匹配** |
| **医学** | UCAT + BMAT | 竞赛 + 义工 + 面试 | ⭐⭐⭐ 需生物（当前无） |

**成绩单直接信号：**
- Maths+Physics双Above Standard → 工程/数学/自然科学方向强力支撑
- English 4/3 → 医学/法律方向受限（医学需要大量文书和面试英语）
- 无Biology → 医学方向缺少基础学科

**结论：工程/数学/自然科学是最优方向，English短板是最大风险**

**建议**：先让Diya做工程 vs 数学 vs 自然科学各方向的信息收集（各3-5个晚上），然后她自己选。兴趣驱动比父母包办更持久。

## 三、Jemma 完整规划（Year 8 → Year 13）

### 3.1 核心策略：6年积累，按节奏推进

Jemma最大的优势是**时间**。规划重心在Year 8-11的积累期，Year 12-13冲刺。

### 3.2 分阶段时间线

#### 【Phase A】Year 8-9 — 探索期
```
目标：发现1-2个真正的学科热情 + 英语学术写作起步
```

**学科探索（Year 8-9）**
- [ ] 多尝试：理工科夏令营/科学馆活动/编程体验
- [ ] 观察哪一科让她真正"入迷"而不是完成任务
- [ ] 记录：每次学到有趣的东西，写下来（未来PS素材）

**英语学术写作（Year 8开始，持续5年）**
```
这是中国学生在英国申请的最大短板
目标：到Year 13时能够用英语流畅表达复杂学术思想

资源（国内/线上）：
- 英国私校辅导老师（iWS等，£40-80/小时）
- R君阅读写作课程（知乎/B站有介绍）
- The Student Room（英国学生论坛，学术写作社区）
- Khan Academy English（学术写作系统课）

关键：不是考雅思，而是学术写作思维方式的训练
```

**课外活动体系化**
- [ ] 乐器/运动（保持1-2个精通，不要太多）
- [ ] 学校社团领导力（Year 9争取一个领导岗位）
- [ ] 义工/社区服务（英国大学看重）

**数学基础（Year 8-9）**
- [ ] UKMT Intermediate Math Challenge（Year 9参加，目标Gold）
- [ ] 如果能力达到：开始挑战Senior级别
- [ ] 建立数学竞赛体系感：每周1-2道难题

#### 【Phase B】Year 10-11 — 积累期
```
目标：GCSE高分 + 竞赛体系 + Summer School + PS素材池
```

**GCSE（Year 10-11）**
```
目标：8-9个A*-A（含Maths + Science核心）
选课建议：
  - 必须：Maths, English, Physics, Chemistry（如果走理工）
  - 强烈建议：Further Maths（如Headington提供）
  - 其他：根据兴趣选择（Computer Science值得考虑）
```

**UKMT + BMO体系（Year 10-11）**
```
Year 10: UKMT Senior Math Challenge → 晋级BMO Round 1
Year 11: BMO Round 1 + BMO Round 2（如晋级）

目标：Year 11时能拿到BMO Medal（和牛剑申请直接挂钩）
```

**Summer School（Year 10-11暑假）**
```
Year 10暑假：
  - Headington或其他英国私校夏令营（体验英国教育）
  - 科学类夏令营（STEM方向）

Year 11暑假（关键）：
  - UNIQ（Oxford免费夏校）
  - Imperial Summer School
  - 科研项目（国内/英国大学实验室）
  - 美国名校夏校（如YYGS，Tammy能力够的话）
```

**PS素材积累（Year 10-11）**
```
- 学术阅读笔记：每学期至少2本课外学术书籍（数学/物理/工程）
- EPQ准备：Year 11确定选题方向
- 项目经历：任何独立完成的工程/科学项目都算
```

## 七、PS（个人陈述）+ 面试准备策略

### 7.1 PS写作时间线

```
Year 10-11：素材积累期（阅读/竞赛/项目/夏校）
Year 12（9月）：初稿
Year 12（10月）：修改
Year 12（11月）：定稿
```

### 7.2 PS核心结构（理工科）

```
第一段：开头钩子 — 为什么对这个学科感兴趣（要具体！）
第二段：学术兴趣证据1 — 竞赛/项目/深入阅读（要有深度）
第三段：学术兴趣证据2 — 夏校/独立研究/竞赛（展示持续投入）
第四段：课外活动 + 领导力 — 展示全人发展
结尾：为什么这所大学 — 定向展示
```

### 7.3 理工科PS加分项
- **独立项目**：自己做的数学建模/物理研究/编程项目
- **深度阅读**：读完一本专业书后有自己的思考（不是书名罗列）
- **竞赛成绩**：BMO Medal/ BPhO Gold/ UKMT gold是硬通货
- **Summer School经历**：UNIQ/Imperial夏校是重要背书

### 7.4 面试准备

**常规准备：**
- 前5分钟：自我介绍 + Why this course（最常问）
- 中间20-25分钟：学科讨论（问题无标准答案，考思维过程）
- 最后5分钟：问面试官问题（必须准备1-2个问题）

**理工科面试关键：**
- 不要猜答案，要展现思考过程（"Let me think..."）
- 画图/列公式是好的沟通方式
- 如果不懂，直接说不懂，但尝试给出思路

**练习资源：**
- Cambridge官方面试示例（YouTube有）
- The Student Room UK（英国学生面试经验分享）
- Headington学校模拟面试（问学校有没有）
- 外部机构：The Ruskin Group（Oxford校友面试培训）等
